# FAQ

**Q: 这是能直接训练的模型吗？**
参考实现用 skill 代理学习动力学；backbone 是真实前向（embedding+attention+MoE），
`train.optimizer` 预留了真实权重训练路径。

**Q: 为什么零依赖？**
便于任何环境秒级复现；所有矩阵运算用纯 Python 实现（`utils/linalg`）。

**Q: 扩散和自回归到底差在哪？**
自回归串行 L 步；扩散固定 T 步并行去噪，串行步数与序列长度解耦。

**Q: 联合决策一定比独立准吗？**
当单条判断有噪声时，聚合（Copeland）通常更准（大数定律）；完美判断下两者
都最优。
