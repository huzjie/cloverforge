# 离散扩散（mask-and-predict）

## 为什么不是自回归

自回归从左到右逐 token 生成，第 i 个 token 要等前 i-1 个都出完——序列越长，
串行步数越多。扩散语言模型反过来：**先把整段输出全部掩码，再用固定的 T 步
并行"去噪"**，每一步同时预测所有未揭晓的位置。串行步数从 L 降到 T，这就是
"部分场景快 5-10 倍"的来源。

## 前向过程（腐蚀）

给定干净序列 x_0，按比例 alpha 随机掩码若干 token：

    x_t = mask(x_0, ratio=1 - alpha_bar(t))

alpha_bar(t) 是"已揭晓比例"的调度（线性或余弦），t 越大揭晓越多。

## 反向过程（去噪）

```
x = [prompt] + [MASK] * gen_len
for t in 1..T:
    logits = denoiser(x)                 # 并行预测所有被掩码位置
    keep   = 按置信度排序的前 alpha_bar(t)*gen_len 个预测
    x      = 揭晓 keep，其余保持 MASK
```

## 置信度重掩码

每一步只揭晓**置信度最高**的那批 token（softmax 最大概率），低置信度的继续
掩码等下一轮。这样模型先锁定"确定的部分"，再用已确定的部分去约束"不确定的
部分"——整体一致性来自多轮互证，而不是单向贪心。
