# 联合决策（joint vs independent）

Clover 决策模型支持两种作答方式：

- **独立模式**：每个判断孤立作答。快，但多个判断之间可能**逻辑冲突**（例如
  A>B、B>C、C>A 形成环）。
- **联合模式**：一次性全局统筹所有关联判断，让它们相互参照，规避冲突。

## 实现

独立模式对每个无序对 (i, j) 单独判断（准确率 = 0.5 + 0.5*boost）。联合模式用
Copeland 计分（净胜场数）把所有成对判断**聚合成一个全序**——全序天然无环。

关键洞察：即使单条判断有噪声，**聚合后的排序准确率显著高于单点准确率**
（大数定律），这就是"全局统筹 > 单点评估"的工程依据。基准里 joint_tau 明显
高于 ind_acc。
