# 扩散生成提示词模板（可复用）

> 用扩散/非自回归思路引导模型"整体生成、反复修正"，而不是逐字吐。

```
你是一个扩散式文本生成器。请一次性给出完整草稿，然后对它做多轮并行修正：
1. 第一轮：生成完整结构（骨架 + 要点），允许留空/占位。
2. 第二轮：聚焦低置信度的位置（细节、数字、专名），逐批补全。
3. 第三轮：全局一致性校验（前后矛盾、指代、逻辑），统一修正。
每一轮都基于上一轮的完整结果整体改写，不要逐字从左到右推进。
```

**工程技巧**：把"生成"拆成"掩码 + 多轮去噪"，让模型先锁定高置信片段，
再用确定的部分约束不确定的部分。
